SYSTEM-TO-SYSTEM

Approved results integration

The school results system submits finalized batches. No parent accounts are created.

Checking integration configuration…
1
Approve results in the school system

Only a completed, approved exam batch should be shared.

2
Post the batch to the secure API

POST /api/integrations/results/batches with the X-Integration-Key server-side header.

3
Results import and guardian messages queue together

Stable batch/result IDs prevent duplicates. Learners without registered guardian phone numbers are counted for follow-up.

4
Configure Africa's Talking

Add the provider credentials to the backend environment and enable the SMS worker to send queued messages.
